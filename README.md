# 情绪菜园

手机浏览器里完成：面部表情识别（位置自动确定，识别不对可在摄像头页点"调整"用转盘改）→ 在一个圆形"情绪圆圈"（43 个 emoji 排成蜂窝圆盘）里选最贴近的表情（圆盘里每个格子就是一张蔬菜表情图；强度 1–7 级，选中的那张就是你种下的这一株）→ 选特殊状态 → 听声音 → 种进校园地图。
点"确认并保存"后，记录自动发到电脑，追加为 `records.csv`（Excel / WPS 直接打开）。

- 面部识别、声音合成全在**手机本地**运行。摄像头画面只在内存里用约 6 秒，**不录制、不保存、不上传**，识别完立即关闭摄像头。
- 只有文字记录（地点、情绪、强度、特殊状态、乐器、置信度）会发到电脑。
- 全程只需要局域网，**不需要联网、不需要隧道**（下载识别库那一步除外，只做一次）。

## 一、电脑上准备（一次）

1. 安装 Python 3（python.org，Windows 安装时勾选 *Add to PATH*）。Mac/Linux 自带 openssl；Windows 如果没有 openssl，装 Git for Windows 即可（自带）。
2. 解压本压缩包。
3. 下载识别库和模型（约 2~3 MB，只做一次）：
   ```
   python download_vendor.py
   ```
   成功后 `vendor/` 里有 `face-api.js` 和 `model/` 下 4 个文件。
   下载失败（网络原因）可手动下载，放到对应位置：
   - 在 npm 镜像（如 registry.npmmirror.com）或 jsdelivr 上找包 `@vladmandic/face-api`
   - `dist/face-api.js` → `vendor/face-api.js`
   - `model/` 下的 `tiny_face_detector_model.bin`、`tiny_face_detector_model-weights_manifest.json`、`face_expression_model.bin`、`face_expression_model-weights_manifest.json` → `vendor/model/`

## 二、启动

- Windows：双击 `start.bat`
- Mac：终端运行 `bash start.sh`（或双击 `start.command`，首次需 `chmod +x`）
- 或手动：`python server.py`

终端会显示类似：

```
电脑本机打开： https://localhost:8443/
手机打开（需与电脑同一 Wi-Fi）： https://192.168.1.23:8443/
```

首次启动会自动生成自签名证书。如果电脑换了网络（IP 变了），下次启动会自动重新生成。

## 三、手机使用

1. 手机和电脑连**同一个 Wi-Fi**（注意：有些校园网/公共 Wi-Fi 开了"AP 隔离"，设备间互相访问不了，此时用手机热点给电脑连，或让电脑开热点给手机连）。
2. 手机浏览器打开终端里显示的"手机打开"地址。首次会提示"连接不安全/证书无效"（自签名证书的正常现象）：
   - iPhone Safari：点"显示详细信息" → "访问此网站"
   - Android Chrome：点"高级" → "继续前往"
3. 想直接定位到某个地点（贴二维码用）：在地址后加 `?zone=library`，可选值：
   `class` 教学楼 · `library` 图书馆 · `dorm` 宿舍 · `canteen` 食堂 · `field` 操场 · `garden` 菜地
   例：`https://192.168.1.23:8443/?zone=canteen`
   没带 `?zone=` 时：校园坐标已配置则静默用 GPS 定位，否则随机给一个地点；摄像头页左上角的"📍 地点 · 调整"可以手动改。
   界面语言：页面右上角的「EN / 中文」按钮一键切换，选择会记住；也可用 `?lang=en` / `?lang=zh` 指定（默认跟随浏览器语言）。发到电脑的 `records.csv` 始终是中文，不受界面语言影响。
   调试用：地址加 `?debug=1` 会在摄像头页多出"模拟识别 / 跳过"两个按钮（正式使用不显示）。
4. 走完流程，点"确认并保存"。电脑终端会打印"收到记录"，`records.csv` 增加一行。
5. 可选：浏览器菜单 →"添加到主屏幕"，之后全屏打开。

## 四、记录表字段（records.csv）

| 列 | 含义 |
|---|---|
| id | 记录唯一编号（手机重发时用来去重） |
| server_time | 电脑收到的时间 |
| client_time | 手机上点保存的时间（UTC） |
| zone | 地点 |
| emotion | 情绪类别（愤怒/乐观/平静/痛苦/放松） |
| emoji / word | 选中的具体表情和名称（如 😌 放松 Relaxed） |
| level / solfege / stage | 强度 1~7（离圆圈中心越远越强）/ 对应音名 / 植物生长阶段 |
| special | 特殊状态（无则为空） |
| instrument | 乐器 |
| confidence | 识别置信度（手动选择则为空） |
| device | 手机浏览器信息 |

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 摄像头报"无法使用摄像头" | 必须用 `https://` 地址打开，并允许相机权限 |
| 摄像头提示识别库加载失败 | 没运行 `download_vendor.py`，或 `vendor/` 文件缺失 |
| 手机打不开页面 | 不在同一 Wi-Fi；电脑防火墙拦截了 8443 端口（Windows 弹窗时选"允许"）；网络有 AP 隔离 |
| iPhone 没声音 | 把侧边静音拨片拨到响铃；不要用微信内置浏览器，用 Safari |
| 保存后电脑没记录 | 页面底部会显示"待同步 N 条"，电脑开着服务器且网络恢复后每 15 秒自动重发，不会丢 |
| 终端提示 records.csv 被占用 | Excel 正开着它。关掉，或先复制一份再看；手机会自动重发 |
| 想清空数据 | 停掉服务器，删除 `records.csv` |

## 六、传到 GitHub

直接把整个文件夹提交即可。`.gitignore` 已排除 `records.csv`、证书和私钥，**数据和私钥不会被上传**。
`vendor/` 建议一并提交（这样别人 clone 后不用再下载）。

## 演示模式（不连后端也能用，同一个链接）

页面启动时会探测"提供这个页面的服务器"有没有 `/api/ping`：

| 打开方式 | 模式 | 行为 |
|---|---|---|
| 电脑上 `python server.py` 提供的地址 | 正常 | 记录自动发到电脑，写进 `records.csv` |
| GitHub Pages 等静态托管的同一个链接 | **演示** | 完整交互，不排队、不重试、不上传任何东西；右下角有 `DEMO` 标记，第 5 步提示"演示模式" |
| 任何地址后面加 `?demo=1`（或直接双击打开 `index.html`） | **演示** | 同上；现场只想展示界面、又不想污染数据时用 |
| 页面在别处、加 `?api=https://电脑地址` | 正常 | 记录发回你的电脑（只需设置一次，会记住） |
| 探测不到（断网/超时） | 暂不确定 | 当作"后端暂时离线"，记录先排队，恢复后自动重发，不丢数据 |

演示模式下"你种的植物"仍保存在访问者自己的浏览器里（用来画花园），不会发给任何人；清除浏览器网站数据即可清空。

**用 GitHub Pages 发布**：仓库 Settings → Pages → Source 选 *Deploy from a branch*，分支选要发布的那个（如 `vege-plates` 或合并后的 `main`），目录 `/ (root)`。链接是 `https://<用户名>.github.io/<仓库名>/`。Pages 自带 HTTPS，手机摄像头可以直接用；识别库在 `vendor/` 里，不用联网下载。

> 要在 Pages 页面上同时收集真实数据：电脑端需要有 HTTPS 地址（局域网自签名地址不行，浏览器会拦截"HTTPS 页面访问 HTTP/不受信任地址"），再用 `?api=` 指过去。现场演示请直接用 `server.py` 同时提供页面和接收记录。

## 七、想改表情图 / 蔬菜

都在 `index.html` 里：
- 蔬菜表情图：`assets/veges/<植物>/<植物>-<中文名>.png`（chili / corn / mushroom / eggplant / cabbage；共 43 张，另有一张备用 `chili-脑袋爆炸.png`，目前没排进圆盘）。图会被自动裁掉透明边；换图直接同名覆盖即可
- 改名字 / 改类别 / 改强度：`MOOD_INFO`（`emoji: [类别, 中文, English, 强度]`，emoji 字符现在只当唯一 id 用，不再显示）；强度要和图的文件名「程度N」保持一致
- 挪 emoji 的位置：`MOOD_ROWS`（蜂窝圆盘，一行一行，每行自己居中；43 格）
- 情绪圆圈的方向提示：四边常驻淡淡的「高能量 / 低能量 / 不愉快 / 愉快」，一条虚线十字标出地图中心；往哪个方向拖，视野前往的那一侧会发光、标签亮起。
- 英文文案：界面文字写成 `T('中文','English')`；情绪/植物/地点/乐器/特殊状态的英文在 `EN_DATA`。

## 八、植物动效（motion/ 文件夹）
选好特殊状态（发疯 / 接好运 / 浪 / 疲惫 / 搬砖）后，第 3、4 步的植物会播放设计同学做的动效。
- 动效在浏览器里用画布实时渲染（`motion/engine.js`），不需要预渲染的动画图片；**必须通过 http(s) 打开**（server.py 或 GitHub Pages 都可以，直接双击 index.html 的 file:// 不行，这时会自动显示静态植物）。
- 引擎在进入第 2 步时才开始加载；加载失败时只显示静态植物，不影响其它功能。
- 植物原图在 `motion/plants/`（最长边已缩到 640px），每株的眼睛、帽檐位置记录在 `motion/profiles.json`，名称与编号对照在 `motion/catalog.json`。
- 新增一株植物：在 `catalog.json` 加一条记录、把 PNG 放进 `motion/plants/`、在 `profiles.json` 补坐标，再到 `index.html` 的 `MOTION_ID` 里加「中文名 → ID」。详见 `motion/INTEGRATION.md`。

## 九、「植物被互动了」提示页（notice/ 文件夹）
公共装置上有人和我们的蔬菜互动后，个人设备会收到一条通知、点开看到这次互动的结果和一份心情安抚。个人设备这边只负责「收到提示」，互动本身发生在公共装置。共 5 种：

| kind | 公共装置上的互动 | 个人设备看到的 |
|---|---|---|
| `water` | 水管阀门 | 着火的愤怒辣椒被浇水，火被淹灭 |
| `sun` | 阳光滑块 | 悲伤茄子被阳光照到，变成气球飞走 |
| `poke` | 手指戳戳 | 平静蘑菇被戳三下，脸红冒爱心 |
| `heat` | 加热火 | 开心玉米被烤热，啪！变成爆米花 |
| `hammer` | 锤子 | 放松卷心菜（木鱼）被敲响，收获安静与平静 |

- **入口**：第 1 页（摄像头页）标题说明下面有一个虚线小按钮「🌱 查看「植物被互动了」提示 · 演示」，点它进入；也可以用链接直达：`?notice=water`（或 `sun` / `poke` / `heat` / `hammer`）。
- **流程**：锁屏样式的通知横幅落下 → 点通知 → 互动动画 + 安抚卡片 →「收下这份安抚」。页面顶部的 5 个小图标可以切换看 5 种；「↻ 重播」重放动画；「返回」回到第 1 页。
- **接真实消息**：以后公共装置发来互动事件时，调用 `showPlantNotice('water')`（参数就是上面的 kind）即可弹出对应的提示页。
- **用哪张蔬菜图**：如果这位用户自己种过同类蔬菜（比如种过茄子），就用 TA 最近种的那一张；没种过就用默认的一张（`notice/notice.js` 里 `KINDS[...].def`）。
- **改动画 / 文案**：全部在 `notice/notice.js`。每个场景是一条按「秒」写的时间轴（`BUILD.water` / `sun` / `poke` / `heat` / `hammer`），想调节奏就改数字；文案在 `KINDS`（中英文都有）。样式在 `notice/notice.css`。动画是纯 CSS / SVG，不需要额外图片，也不联网；系统开了「减少动态效果」时直接显示最终画面。
